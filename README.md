# 🌐 Traductor Multilingüe Interactivo en Terminal

Una aplicación de consola interactiva y estilizada desarrollada en Python. Esta herramienta permite realizar traducciones instantáneas de textos y fragmentos literarios hacia múltiples idiomas, diseñada específicamente como un apoyo para el análisis de lectura, la extracción de vocabulario y el desarrollo de la fluidez lingüística.

## 🚀 Características

* **Interfaz de Usuario Atractiva:** Uso de la librería `rich` para una experiencia en terminal con paneles, colores y animaciones de carga.
* **Traducción Precisa:** Integración con `deep-translator` para traducciones estables y automáticas.
* **Soporte Multilingüe:** Capacidad para traducir desde cualquier idioma (detección automática) hacia:
  * Inglés (`en`) - *Ideal para diseccionar literatura y estructuras gramaticales.*
  * Chino Simplificado (`zh-CN`)
  * Finés (`fi`)
  * Italiano (`it`)

## 🤖 Desarrollo Asistido por IA (Pair-Programming)

Este proyecto fue desarrollado utilizando metodologías de **Pair-Programming con Google Gemini**. El uso de Inteligencia Artificial permitió:
1. Estructurar el flujo de trabajo de control de versiones (Git/GitHub).
2. Optimizar la lógica de importación y el manejo de excepciones (`try-except`) en Python.
3. Diseñar una interfaz de consola de alta calidad.
